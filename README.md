# ⚔️ قبضة الجنرال — The General's Fist

لعبة استراتيجية Idle واقعية من نوع Low-Poly Isometric 3D

## 🎮 الأنظمة الأساسية (المجموعة الأولى)

| النظام | الوصف |
|--------|-------|
| 🗺️ **خريطة العالم** | 61 قطاع سداسي + ضباب حرب + استطلاع |
| ⚔️ **غرفة العمليات** | مشهد 3D إيزومتري + نشر القوات + حساب القوة |
| 🏰 **الثكنات** | تجنيد + قيادة هرمية (سرايات + حظائر + قادة) |
| ⚙️ **الإنتاج التلقائي** | 5 منشآت + ترقيات أسّية + موارد Idle |
| 🎯 **محرك المعارك** | محاكاة 3D + 5 تكتيكات نشطة + AI |

## 🔬 الأنظمة الواقعية (المجموعة الثانية)

| النظام | الوصف |
|--------|-------|
| 🌤️ **الطقس الدينامي** | 6 أحوال جوية + معاملات لكل نوع قوات + انتقالات واقعية |
| 💖 **الروح المعنوية** | 5 مستويات + 12 عامل مؤثر + تحديث ديناميكي أثناء المعركة |
| 😴 **التعب والإرهاق** | 4 مستويات + تراكم أثناء القتال + نقصان بالراحة |
| 📦 **الإمدادات والذخيرة** | 5 أنواع + استهلاك 3× أثناء القتال + عقوبات النفاد |
| ⚔️ **جدول الفعالية** | Rock-Paper-Scissors: مشاة×2←مدرعات، طيران×2.5←مشاة |
| 🩹 **نظام الإصابات** | 4 حالات: سليم ← مصاب ← حرج ← قتيل |
| 🔬 **شجرة البحث** | 13 تقنية على 3 مستويات + متطلبات + مكافآت تراكمية |
| 🧮 **المعادلة الشاملة** | 9 معاملات تتراكمية تحسب القوة الفعلية النهائية |

## 🧮 المعادلة الشاملة للقتال

```
الهجوم الفعّال = قاعدة_الهجوم
  × فعالية_نوع_القوات (جدول RPS)
  × معامل_الحالة (سليم/مصاب/حرج)
  × معامل_الروح_المعنوية (5 مستويات)
  × معامل_التعب (4 مستويات)
  × معامل_الطقس (6 أنواع)
  × معامل_الوقت (فجر/نهار/غسق/ليل)
  × معامل_الإمداد (ذخيرة/وقود)
  × مكافآت_التكتيكات_النشطة
  × مكافآت_التقنيات_المبحوثة
  × مكافآت_القادة
```

## 🛠️ التقنيات

- **Next.js 16** + TypeScript + Tailwind CSS 4
- **Three.js** + React Three Fiber (3D Low-Poly Isometric)
- **Zustand** (State Management)
- **shadcn/ui** Components

## 📱 وضعية اللعب

- Portrait Mode (طولي) — بيد واحدة
- Isometric Camera (إيزومتري)
- محسّن للهواتف الضعيفة (DPR محدود, Low-Power GPU)

## 🚀 التشغيل

```bash
npm install
npm run dev
```

## 🎯 تدفق اللعب الكامل

1. **الثكنات** → تجنيد + تعيين قادة + ترقية منشآت + بحث
2. **غرفة العمليات** → تضاريس + طقس + توقيت + نشر موجات
3. **خريطة العالم** → استطلاع + هجوم على القطاعات
4. **المعركة** → تكتيكات + روح معنوية + إمدادات + سجل المعركة
5. **الغنائم** → موارد + تحرير قطاع + تحديث المعنويات
