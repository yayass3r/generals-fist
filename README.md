# ⚔️ قبضة الجنرال — The General's Fist

لعبة استراتيجية Idle من نوع Low-Poly Isometric 3D

## 🎮 الأنظمة المتكاملة

| النظام | الوصف |
|--------|-------|
| 🗺️ **خريطة العالم** | 61 قطاع سداسي + ضباب حرب + استطلاع |
| ⚔️ **غرفة العمليات** | مشهد 3D إيزومتري + نشر القوات + حساب القوة |
| 🏰 **الثكنات** | تجنيد + قيادة هرمية (سرايات + حظائر + قادة) |
| ⚙️ **الإنتاج التلقائي** | 5 منشآت + ترقيات أسّية + موارد Idle |
| 🎯 **محرك المعارك** | محاكاة 3D + 5 تكتيكات نشطة + AI |

## 🛠️ التقنيات

- **Next.js 16** + TypeScript + Tailwind CSS 4
- **Three.js** + React Three Fiber (3D Low-Poly Isometric)
- **Zustand** (State Management)
- **shadcn/ui** Components

## 🚀 التشغيل

```bash
npm install
npm run dev
```

## 📱 وضعية اللعب

- Portrait Mode (طولي) — بيد واحدة
- Isometric Camera (إيزومتري)
- محسّن للهواتف الضعيفة (DPR محدود, Low-Power GPU)

## 🎯 تدفق اللعب

1. **الثكنات** → تجنيد قوات + تعيين قادة + ترقية المنشآت
2. **غرفة العمليات** → اختيار التضاريس والتوقيت + نشر الموجات
3. **خريطة العالم** → استطلاع قطاع + بدء الهجوم
4. **المعركة** → استخدام التكتيكات + متابعة القتال
5. **الغنائم** → موارد إضافية + تحرير القطاع

## 📐 المعادلة الرياضية

```
القوة الفعالة = Σ(قاعدة_القوات × انجذاب_تضاريسي × انجذاب_زمني) × معامل_دفاع_التضاريس × معامل_التوقيت × مكافأة_الموجات
```
